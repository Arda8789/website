# Fortify — Yazılım Çözümleri

Fortify'ın tanıtım sitesi. Statik HTML/CSS/JS ile hazırlandı, Railway üzerinde
GitHub'dan sürekli dağıtımla yayınlanıyor.

## Yerel çalıştırma

```bash
npm start
```

`http://localhost:3000` adresinden açılır.

## Dağıtım

`main` dalına yapılan her push, Railway'de otomatik olarak yeni bir dağıtım tetikler.
